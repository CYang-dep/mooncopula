# MoonCopula 工程边界

公开数据模型以不可变、受校验的 Copula 和长度受限的配对数组为中心。纯计算，不读取网络/文件/环境凭据。概率为闭区间[0,1]；密度、似然和条件反解只接受开区间，避免把边界奇点偷偷裁成有限值。

参数范围有界以限制数值病态：Clayton正参数、Gumbel>=1、Frank双号；精确范围随实现的校验契约。拟合是有界确定性一维优化，不宣称全局最优或统计显著。经验概率使用<=定义，样本模拟使用调用者提供的均匀数组而非隐藏随机源。

验收：方程对照、CDF边缘/Frechet/二维递增、条件往返、积分/导数、秩并列语义、无效输入、配置预算、经验边缘与三类下游样例。无高维/vine、Gaussian/t、不处理缺失/无穷、不提供医疗/金融/工程安全保证。CI四后端验证，Windows native如缺工具链由Linux CI证明。
